# 量筒的密室杀手

欢迎您访问该项目！该项目旨在在基岩版尽可能地还原 Hypixel 的密室杀手（Murder Mystery）小游戏。

该项目由珂朵莉（Tetrisoo，@VioletMiaw）和欧拉（Freamoluwu）大力赞助并支持，并且由测试群（QQ：673941729）中的群友进行测试。感谢为这张地图做出贡献的人！

该地图至少需要使用 26.40 或更高版本游玩。

请注意：该项目使用 GPL 协议。您可以使用其中的源代码，但必须同样使用 GPL 协议并开源。

## 项目构建

该项目使用 TypeScript 编写。

如果你对源码不感兴趣，只想要一个能玩的地图，我们也有地图可供您下载。您可以在右侧的 Release（手机页面在下方）找到我们发布的地图。按照对应页面进行操作，下载地图后即可游玩。

我们的地图安装了自定义头颅，使用了南瓜汁（@PumpkinJui）的脚本进行代码生成。您可以在 [mm_head 仓库](https://github.com/PumpkinJui/mm_head)了解更多。

如果还有什么想要了解的，请联系我们的 QQ 群，进群申请填写为「GitHub 密室杀手」。

## 1.0 - Pre 2 更新日志

提前预祝大家国庆节快乐！我们计划在 10 月 3 日发布最终的 RC 版本，因此这个版本将会是最后一个预览版本了。我们将会在 10 月 1 日发布最终的 RC 版本，欢迎大家积极参与测试！

我们在这次的更新中添加了众多设置，并且改进了定位器的运作方式。虽然我们仍然没能修复定位器的退出重进失效问题……（我们真的尽力了！这真的是在给原版擦屁股，真的很累……）

一起来看看本周的更新吧，祝你躲过杀手的追击！

### 地图

- 降低了地图阴森庄园的挤压陷阱启动延迟，现在能更快地启动挤压陷阱了
- 实装了港口小镇地图（包括 V1）的所有功能：溺水判定、水肺药水、抬桥陷阱
- 新增了神秘药水对其他资源包的适配

### 地图交互

- 修复了玩家可以和信标交互的问题

### 设置

- 同步了测试员名单

### 技术性

- 更新了行为包和资源包的版本为`1.0.21`
- 为密室杀手组件新增了`keepSaturation`通用组件
- 现在地图默认使用困难难度，而非和平难度
- 为密室杀手玩家新增了`dealDamage`方法，用于对玩家施加伤害，并自动判断是否应该将玩家处死（而不是在游戏层面上将玩家杀死）
- 移除了密室杀手系统`beforeGameInfo`中的最小玩家数和最大玩家数，现在系统直接调用系统设置的值
- 将密室杀手组件的`interaction`组件拆分为了`interaction`组件、`playerPressButton`组件、`playerPushLever`组件
- 新增了`playerInteractWithEntity`组件，支持传入实体应有的标签，并在和特定标签的实体交互后执行事件
- 新增了`playerUsedItem`组件，支持传入允许使用的物品 ID，并在使用了这些物品后执行事件
- 移除了`data.ts`的`enableMysteryPotion`组件，现在应该用`playerUsedItem`组件
- 新增了水肺药水`murder_mystery:water_repellent_potion`自定义物品
- 移除了事件管理器的`inPotionEffect`属性，移动到了密室杀手玩家的`isInPotionEffect`属性中
- 更新了密室杀手玩家的`canGiveItem`方法，现在接受一个`customMessage`参数
