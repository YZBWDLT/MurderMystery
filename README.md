# 量筒的密室杀手

欢迎您访问该项目！该项目旨在在基岩版尽可能地还原 Hypixel 的密室杀手（Murder Mystery）小游戏。

该项目由珂朵莉（Tetrisoo，@VioletMiaw）和欧拉（Freamoluwu）大力赞助并支持，并且由测试群（QQ：673941729）中的群友进行测试。感谢为这张地图做出贡献的人！

该地图至少需要使用 26.40 或更高版本游玩。

请注意：该项目使用 GPL 协议。您可以使用其中的源代码，但必须同样使用 GPL 协议并开源。

## 项目构建

该项目使用 TypeScript 编写。这意味着如果您需要使用源码，您需要做额外的构建工作才能正常使用该项目。

如果你对源码不感兴趣，只想要一个能玩的地图，我们也有地图可供您下载。您可以在右侧的 Release（手机页面在下方）找到我们发布的地图。按照对应页面进行操作，下载地图后即可游玩。

我们这里使用了 Microsoft 提供的工具 just-scripts 构建，您可以在[下一步：用 TypeScript 编写脚本 | Microsoft Learn](https://learn.microsoft.com/en-us/minecraft/creator/documents/scripting/next-steps?view=minecraft-bedrock-stable)了解更多。

我们的地图安装了自定义头颅，使用了南瓜汁（@PumpkinJui）的脚本进行代码生成。您可以在 [mm_head 仓库](https://github.com/PumpkinJui/mm_head)了解更多。

如果还有什么想要了解的，请联系我们的 QQ 群，进群申请填写为「GitHub 密室杀手」。

## 1.0 - Snapshot 7 更新日志

密室杀手中最恐怖的是什么？好吧，除了恐怖的杀手和侦探恐怖的弓法之外，还包括地图中一大堆的史蒂夫头颅！史蒂夫北极熊、史蒂夫人头树等诡异装饰充满了地图！而今天，我们正式实现了这些头颅的替换工作，并全面改进了许多处细节的游玩体验。

一起来看看本周的更新吧，祝你躲过杀手的追击！

1.0 - Snapshot 7b 更新：修复了地图默认被开启为禁止多人的问题，并修复了头颅朝向无法正确显示，部分头颅贴图出错的问题。

### 自定义头颅

- 隆重推出——地图自定义头颅替换工程！
- 经过我们的管理群团队的几位成员（绿叶、南瓜汁、文雨）没日没夜的努力，我们将原地图中的绝大多数自定义头颅都应用在了基岩版
- 使用自定义方块技术制作的自定义头颅替换了所有的玩家头颅
- 现在你再也不会看到人头树了！
- 备注：因为自定义头颅的工作量极大，我们一共向游戏添加了 340 种头颅，合计在游戏内应用了超过 1000 个头颅，因此目前还存在一些问题，包括贴图错误、头颅替换遗漏等情况，预计会在未来的 1~3 个版本内彻底解决

### 地图

- 略微扩大了地图高坠塔的范围
- 对多张地图的多处细节都进行了修改和修复
- 新增地图水上度假村

### 神秘药水

- 更换了 5 种药水的贴图，现在使用更加鲜艳的颜色，可以轻易分辨不同药水了
- 现在神秘药水的迅捷效果结束后，不再会彻底顶掉杀手的迅捷效果

### 金锭生成

- 现在金锭生成不再只考虑 xz 方向上的距离，并略微增大了金点检查半径

### 设置

- 现在在玩家死亡后，会直接打开设置页面，并在设置内内置了 传送到 设置项
- 新增了 3 项设置：侦探弓冷却、最大选取金点数、飞刀冷却

### 漏洞修复

- 现在游戏内可以开启灵动视效（Vibrant Visuals）和光线追踪（Ray Tracing）了
- 修复了存活玩家判断错误而导致的一系列问题
- 修复了矿车可能会被破坏的问题，现在即便被破坏也能迅速恢复
- 修复了按钮在被按下后尝试交互仍然能触发事件的问题

### 技术性

- 更新了行为包和资源包的版本为`1.0.14`
- 将地图中的所有头颅定义全部分离，成为一个单独的包
  - 后续我们会将此包发布在 GitHub 的一个分支上
- 为设置新增了开发者设置
  - 该设置需要玩家拥有`developer`标签，并且玩家是管理员
  - 添加了 2 个设置：新增 1 名假玩家、移除所有假玩家
- 移除了`preventDamage`组件，该组件原本是为画、矿车、盔甲架而准备的，但现在它们在该组件下都无法工作
- 现在从`interaction`组件中提取了`consume`功能，到`consumeGold`事件响应中去，现在尝试消耗金锭应当在事件中指定
- 优化了`interaction`组件的类型声明，理论上这并不会影响原有的组件格式
- 现在`interaction`组件接受一个`type`参数，以判断该交互是正常类型（`normal`）还是按下按钮类型（`button`），如果是按下按钮则会交给玩家按下按钮后事件触发事件，而不是玩家与方块交互前事件直接触发
- 为`lib`新增了一个`BlockMatchData`接口声明
- 为`lib`新增了一个解析`"x y z"`形式的位置信息的函数`Vector3.parseString()`静态方法
