# 量筒的密室杀手

欢迎您访问该项目！该项目旨在在基岩版尽可能地还原 Hypixel 的密室杀手（Murder Mystery）小游戏。

该项目由珂朵莉（Tetrisoo，@VioletMiaw）和欧拉（Freamoluwu）大力赞助并支持，并且由测试群（QQ：673941729）中的群友进行测试。感谢为这张地图做出贡献的人！

该地图至少需要使用 26.30 或更高版本游玩。

请注意：该项目使用 GPL 协议。您可以使用其中的源代码，但必须同样使用 GPL 协议并开源。

## 项目构建

该项目使用 TypeScript 编写。这意味着如果您需要使用源码，您需要做额外的构建工作才能正常使用该项目。

如果你对源码不感兴趣，只想要一个能玩的地图，我们也有地图可供您下载。您可以在右侧的 Release（手机页面在下方）找到我们发布的地图。按照对应页面进行操作，下载地图后即可游玩。

我们这里使用了 Microsoft 提供的工具 just-scripts 构建，您可以在[下一步：用 TypeScript 编写脚本 | Microsoft Learn](https://learn.microsoft.com/en-us/minecraft/creator/documents/scripting/next-steps?view=minecraft-bedrock-stable)了解更多。

如果还有什么想要了解的，请联系我们的 QQ 群，进群申请填写为「GitHub 密室杀手」。

## 1.0 - Snapshot 6 更新日志

我们在本周还带来了重磅更新——完全实装设置功能！现在你可以在设置中控制地图的运行方式，也可以控制何种地图将会启用，等等。通过设置，这张地图就可以玩出很多花活了！

### 设置

- 隆重推出剩下的设置项！
- 现在应用设置可以全局保存，无论`/reload`还是重开游戏都可以自动应用上次的更改
- 对于管理员，可以随时使用`/give @s murder_mystery:settings`获取设置物品，并随时应用设置更改
- 实装了启用地图设置，现在可以控制哪些地图可以生成，哪些地图不能生成
  - 这同样也会影响每局之后的随机地图生成，也就是只要禁用一张地图，那么这张地图不能在设置中选中，也不能随机生成，只能启用后才能游玩
  - 不能把所有地图全部关闭，会阻止设置应用
- 实装了游戏前设置，现在可以控制一局的最多最少为多少人，并控制游戏倒计时需要多久
- 实装了游戏时设置，可以控制一局的游戏时长，多久后给予侦探或杀手物品，如何拾起弓，是否对旁观玩家显示职业和是否全局启用夜视效果 5 个设置
- 实装了金锭生成设置，控制金锭以何种频率和密度生成
- 实装了杀手刀剑设置，控制杀手飞刀如何运行
- 实装了杂项设置，目前可控制右侧信息栏最底下一行的文本

### 漏洞修复

- 现在在尝试加载地图运输塔 V1 和运输塔 V2 时不再会发生系统崩溃的错误
- 现在玩家在矿车上死亡或在矿车上系统重置后，不再会无法跳跃了
- 现在玩家不再能卡着鬼屋门的门边进入鬼屋门了

### 技术性

- 将`applyVision`组件更改为全局组件
- 优化了常加载区域的逻辑，现在只用一个`gamingArea`同时进行预载和地图内的常加载区域加载，而不再单独使用`nextMapPreLoad`进行预载，这可以带来更大的实际常加载区域可指定范围和更高的性能
- 彻底移除了`mysteryPotionPrice`设置项
- 现在`mapEnabled`设置项是根据地图数据动态加载的，并为地图数据描述添加了一个新的参数`enableByDefault`，指定地图是否在默认情况下可加载
- 为密室杀手设置新增了`saveSettings`和`loadSettings`两个静态方法
- 为`lib`新增了一个`JSUtil.isPlainObject`方法，以判断一个对象是否为纯对象
